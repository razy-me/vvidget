## Questioned Decisions
- **D-022 Debounced Configuration Persistence**: Resolved. The backend debounce worker now checks the atomic `is_dirty` flag and reads the latest `current_config` upon timer expiration. Any call to `save_immediate` clears the dirty flag and writes immediately, eliminating the risk of stale debounced writes overwriting fresh configuration.
- **D-023 Lazy Settings Window Destruction**: Resolved. `open_settings_window` now calls `unminimize()` prior to `show()` and `set_focus()`, ensuring the window properly unminimizes and restores foreground focus on Windows.
